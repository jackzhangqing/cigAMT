# Local web fonts

The project page uses Source Serif 4 for scholarly headings and abstract text,
Inter for interface and body text, and JetBrains Mono for numerical and code
content. The Latin WOFF2 subsets are served locally, with system-font fallbacks.

All three families are distributed under the SIL Open Font License 1.1.
Their original copyright and license notices are included alongside the fonts:

- `sourceserif4-OFL.txt`
- `inter-OFL.txt`
- `jetbrainsmono-OFL.txt`

`font-sources.json` records the Google Fonts download URLs. Typography and
layout take inspiration from the CIG-Bench project page; cigAMT content and
figures remain specific to this benchmark.
